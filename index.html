Resolve SQL Backups

A private backup automation tool developed and operated by Oleh Protasevych for his own DaVinci Resolve PostgreSQL project libraries.

Purpose

The tool is designed to create encrypted database backup archives, upload them to the owner's Google Drive, manage backup retention, and send backup status notifications through the owner's Gmail account.

Google account access

  • Google Drive: create and manage only files and folders created by this application or explicitly made available to it.
  • Gmail: send backup notifications to addresses configured by the owner. The tool does not request permission to read the mailbox.

Google account access requires the owner's explicit OAuth authorization. This is a personal tool, not a public service with user registration.
