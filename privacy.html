Privacy Policy

Last updated: 12 October 2026

Resolve SQL Backups is a personal backup automation tool operated by its owner. It is not a public service and does not offer user registration.

Google data access and use

Google access is authorized by the owner through OAuth. The tool uses the following permissions:

  • Google Drive (drive.file): upload encrypted backup archives, access metadata, and manage retention of files and folders created by the tool or explicitly made available to it.
  • Gmail (gmail.send): send backup status notifications to recipients configured by the owner. The tool does not request permission to read incoming mail or contacts.

Data is used solely for backup storage, retention management, operational monitoring, and email notifications.

Storage and protection

Backup archives are encrypted before upload. Archive passwords are not included in notification emails. OAuth credentials are stored on the owner's controlled systems with restricted file permissions and are not published on this website.

Operational records may contain backup names, timestamps, sizes, file identifiers, delivery status, and error details. Credentials and archive passwords must not be written to operational logs.

Sharing

Google Drive and Gmail process data to provide their services. Backup access and notification recipients are controlled by the owner. Data is not sold or used for advertising, profiling, or training machine learning models.

Resolve SQL Backups' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Retention and deletion

Backup archives and operational records are retained according to the owner's configured retention rules. The owner can delete stored backups, remove local credentials, and revoke Google access through Google Account settings at any time. Revoking access stops future API access but does not automatically delete previously stored files or sent emails.

This website

This static website has no application login, analytics scripts, or tracking cookies. GitHub Pages hosts it and may process technical request data under GitHub's own privacy statement.
